# Rebecca + The Binding of Isaac

Este puente reemplaza el prototipo viejo. Ya no guarda una clave de Groq, no depende del micrófono de Google y busca el `log.txt` automáticamente.

## Preparación

1. Copiá la carpeta `BotCoop` a la carpeta `mods` de Isaac y activala en el juego.
2. Iniciá Rebecca Companion para tener memoria y voz.
3. Ejecutá `iniciar_isaac.bat`.

Dentro de Isaac, `K` agrega el segundo personaje y `F8` pausa o reactiva el envío de datos. Los comentarios tienen un límite de frecuencia para no gastar créditos innecesariamente.

El mando virtual es experimental y está separado. Se inicia con `iniciar_mando_virtual.bat`. Por seguridad arranca siempre neutral: todavía no se habilita un piloto automático que pueda apretar teclas sin supervisión.
